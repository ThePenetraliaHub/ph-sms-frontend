GRADE REQUIRED ENDPOINTS

1. GET GRADE REPORT FOR A CLASS
Important Query Options: session, term, grade or class
Optional Query Options: sort or filter by any of the field

Expected object type for each student in the array:

interface StudentReport {
  id: string; //report/grade ID
  name: string; // student's full name
  student_id: string; //student'ID
  academic_grade: string;  // e.g. A or B or C
  report_status: "published" | "unpublished" | "withheld";
  date_generated: string;
  time_generated: string;
  file: report.pdf //automatically generated from the BE
}
